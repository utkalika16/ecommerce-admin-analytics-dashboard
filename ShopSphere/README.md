# ShopSphere - E-Commerce Admin & Analytics Dashboard

ShopSphere is a responsive static e-commerce administration dashboard created for the Deploython 2.0 deployment hackathon.

## Features

### Core Features

- Responsive admin dashboard
- Sidebar navigation
- Revenue overview
- Order overview
- Customer overview
- Product overview
- Product management
- Inventory management
- Low-stock alerts
- Order management
- Order filtering
- Order sorting
- Order status management
- Analytics dashboard
- Revenue visualization
- Responsive design
- Free static deployment support

### Additional Features

- Interactive revenue charts
- Date-range analytics
- Inventory alerts
- Drag-and-drop dashboard widgets
- LocalStorage persistence
- Product editing modal
- Product deletion
- CSV product export
- CSV order export
- Dark/light mode
- Mobile responsive sidebar

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage
- Responsive Web Design

## Pages

- Dashboard
- Products & Inventory
- Orders
- Analytics

No backend is required.
